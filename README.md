
# Minecraft Server Project

Projeto de implementação de um servidor Minecraft utilizando
Debian 13 e Minecraft Forge 1.20.1, desenvolvido com a
finalidade de demonstrar conceitos fundamentais de servidores,
redes de computadores e administração de sistemas.

## 🎯 Objetivos

- Compreender o funcionamento de um servidor de computadores.
- Demonstrar a comunicação entre diferentes máquinas.
- Estudar conceitos de redes e infraestrutura.
- Implementar um servidor utilizando Linux.
- Explorar ferramentas de gerenciamento e administração de serviços.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| Debian 13 | Sistema operacional do servidor |
| Minecraft Forge 1.20.1 | Plataforma do servidor Minecraft |
| Java | Ambiente de execução |
| systemd | Gerenciamento de serviços |
| PufferPanel | Gerenciamento de processos e administração |

## 🖥️ Arquitetura do projeto

O servidor é hospedado e executado em um computador físico.

A máquina emprega o Debian 13 como sistema
operacional e é responsável por executar o servidor
Minecraft.

Os computadores clientes estabelecem conexão com
o servidor através da rede, permitindo a comunicação
e interação dentro do ambiente multiplayer.

## ⚙️ Desenvolvimento

O desenvolvimento foi dividido nas seguintes etapas:

1. Instalação do Debian 13.
2. Instalação e configuração do Java.
3. Instalação do Minecraft Forge 1.20.1.
4. Configuração e inicialização do servidor.
5. Implementação do gerenciamento de processos.
6. Testes de conexão entre diferentes computadores.

## 📊 Resultados

Foi possível estabelecer conexão entre diferentes
computadores utilizando o servidor Minecraft.

Os testes demonstraram a comunicação entre clientes
através de uma infraestrutura hospedada em uma máquina
com hardware básico.

Durante os testes também foram observados problemas
de latência e perda de pacotes, evidenciando a
importância do monitoramento e da configuração
adequada da infraestrutura.
